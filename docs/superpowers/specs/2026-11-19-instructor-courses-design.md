# หน้า /instructor/courses — จัดใหม่ให้อ่านง่าย (Design, short)

## ทำไม
อาจารย์เข้าหน้านี้เพื่อดู 2 อย่าง: (1) วิชาที่ตัวเองรับผิดชอบ (2) รายชื่อนักศึกษาที่รับเป็น Lab Boy แล้ว
หน้าปัจจุบันรกเพราะข้อมูลซ้ำ (หัวการ์ด vs ตาราง 6 ช่อง), ป้ายเรียงยาว, กล่องเตือนเหลืองซ้ำทุกการ์ดของวิชาที่เพิ่มเอง, และวิชาหลาย Sec แตกเป็นหลายการ์ด

## เป้าหมาย / ไม่ใช่เป้าหมาย
- เป้าหมาย: วิชา + Lab Boy อ่านได้ในแวบเดียว; ข้อมูลรองพับไว้
- ไม่ใช่เป้าหมาย: เปลี่ยน API, เปลี่ยนการทำงานของคำขอแก้ไข / เพิ่มวิชาเอง / ยกเลิกเชื่อมโยง
- Anti-goal: ซ่อนสิ่งที่อาจารย์ต้องรู้ทันที (เช่น คำขอแก้ไขรออนุมัติ / ถูกปฏิเสธ)

## Approaches
- **A. การ์ดเดียวต่อวิชา แยกบรรทัดตาม Sec (เลือก)** — ตรงกับ 2 คำถามหลัก, ไม่ซ้ำ; รื้อโครงมากสุด
- B. คงการ์ดเดิม ตัดส่วนซ้ำ — แก้น้อย แต่หลาย Sec ยังซ้ำ
- C. ตาราง 1 แถว/Sec — แน่น แต่รายชื่อหลายคนอึดอัด, มือถือต้องเป็นการ์ดอยู่ดี

## การออกแบบ (A)
```
[ค้นหา ชื่อวิชา / รหัส / Sec]                                   [+ เพิ่มวิชาเอง]

วิชาที่สอนตามตารางสอน (N)
┌ 517122  Computer Programming              ภาค 1/2569  [รายละเอียด ▾] ┐
│  Sec 1 · จ 13:00-16:00   Lab Boy 2/3  (สมชาย) (สมหญิง)                │
│  Sec 2 · พ 09:00-12:00   Lab Boy 0/2  ยังไม่มีผู้ผ่านการคัดเลือก      │
└──────────────────────────────────────────────────────────────────────┘
  ▾ รายละเอียด: ชื่ออังกฤษ, หน่วยกิต, ปุ่ม "ขอแก้ไขรายละเอียด" ราย Sec

วิชาที่เพิ่มเอง · ดูเท่านั้น (M)   ← คำอธิบายเรื่องสิทธิ์ 1 บรรทัด ครั้งเดียว
  การ์ดย่อแบบเดียวกัน ไม่มี Lab Boy; ปุ่ม "ยกเลิกเชื่อมโยง" ราย Sec
```
- จัดกลุ่ม: รหัสวิชา + ภาค + ปี + ที่มา (imported / self_added) — *ผู้สร้างตัดสิน*
- เรียง: ปีการศึกษา/ภาคล่าสุดก่อน แล้วตามรหัสวิชา — *ผู้สร้างตัดสิน*
- ป้ายสถานะประกาศ (เปิดรับ/ปิดรับ) แสดงต่อ Sec แบบเล็ก; ป้ายที่มาย้ายไปเป็นหัว section แทน
- คำขอแก้ไขที่ "รออนุมัติ" หรือ "ถูกปฏิเสธ" แสดงเป็นแถบเล็กในการ์ดโดยไม่ต้องกางรายละเอียด
- ตัด FilterChips (ที่มาแยกเป็น 2 section แล้ว); คงช่องค้นหา + empty state เดิม
- มือถือ: บรรทัด Sec ตัดลงเป็น 2 บรรทัด (เวลา / Lab Boy)
- ใช้ Card, StatusBadge, Avatar, Button, EmptyState, CourseEditRequestModal เดิม; แก้เฉพาะ `InstructorMyCourses.tsx` (+ CSS เล็กน้อยใน globals.css)
